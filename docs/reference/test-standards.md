# Test Standards

> Efficiency-class anchor reference. Per-model values are given in the product records.

## Efficiency-Class Standards

| Standard | Category | Grade / value | Basis | Data status |
|---|---|---|---|---|
| EN 1822 | HEPA/ULPA | H10–H14 (EPA/HEPA), U15–U17 (ULPA) | manufacturer catalogue grade table | verified |
| ISO 16890 | HVAC / ventilation | ePM1 / ePM2.5 / ePM10 / ePM coarse | manufacturer catalogue grade table | verified |
| EN 779 | HVAC coarse/medium | G1–G4 / M5–M6 / F7–F9 | manufacturer catalogue grade table | verified |
| ISO 5011 | engine intake | multi-pass efficiency + dust capacity | industry standard | reference |
| ASHRAE 52.2 | HVAC (US) | MERV | manufacturer catalogue | reference |
| UL 900 / DIN 5510 | flame retardancy | fire rating | manufacturer catalogue | reference |

## Standard Applicability Notes

- **EN 1822**: core efficiency classification for cleanroom / high-efficiency filtration; H13/H14 are high-efficiency HEPA, U15+ is ultra-low-penetration ULPA.
- **ISO 16890**: grades by particle-size fraction (PM1/PM2.5/PM10), replacing the older EN 779 medium-grade framing for general ventilation.
- **ISO 5011**: multi-pass test standard for engine intake air filters (efficiency + dust capacity).
- **ISO 4406**: hydraulic-oil cleanliness classification, used in hydraulic-filter selection (see hydraulic category).

## Note

Grade values are drawn from manufacturer catalogue grade tables where published, otherwise stated as industry-typical reference values. See [data-status](../data-status.md).
